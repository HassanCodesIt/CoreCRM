Multi-Tenant & RBAC Notes

Every table must include tenant_id FK with Row-Level Security (RLS) in PostgreSQL. RBAC expansion: add custom roles beyond admin/manager/rep. Permissions matrix: per-module + per-action (create/read/update/delete/export). Audit log: every write operation should append to audit_events with actor, action, entity_type, entity_id, before/after snapshot, IP, timestamp.

SQLite → PostgreSQL Migration Path

Use Alembic for migrations from day 1. Avoid SQLite-only features (JSON functions differ). Add pgvector extension for semantic search (AI embeddings). Connection pooling via PgBouncer. Read replicas for reporting queries. Target: <100ms p95 on reads with proper indexing on tenant_id + entity FKs.

Section H
Security & Compliance Considerations
Critical

🔐 Auth & Access

  • Upgrade JWT to short-lived access tokens (15min) + refresh tokens (30 days)
  • MFA enforcement for admin/manager roles
  • SSO/SAML support (enterprise requirement)
  • IP allowlist per tenant
  • Session management (concurrent login limits)
GDPR/CCPA

🌍 Privacy Compliance

  • Consent management per contact (opt-in/out records)
  • Right to erasure (cascade delete across tables)
  • Data export (DSAR) within 30 days
  • Cookie consent banner for chat widget
  • Data processing agreement (DPA) template
AI Safety

🤖 LLM Guardrails

  • PII masking before every prompt (name, email, phone → tokens)
  • Zero-retention policy with AI providers
  • Output confidence scoring — reject <0.65
  • Human approval gate for high-stakes actions
  • Model output audit log (30-day retention)
Audit

📋 Audit & Compliance

  • Immutable audit log: every create/update/delete
  • WHO + WHAT + WHEN + IP on every event
  • Admin-accessible log viewer with search/export
  • Retention policy (7 years for enterprise)
  • SOC2 Type II readiness checklist
Infra

🛡️ Infrastructure

  • Encrypt all data at rest (AES-256)
  • TLS 1.3 in transit, HSTS enforced
  • Daily automated backups with point-in-time recovery
  • Rate limiting: 1000 req/min per tenant, 100 req/min per user
  • Secrets management (HashiCorp Vault or AWS Secrets Manager)
Enterprise

🏢 Enterprise Requirements

  • Custom data residency (EU/US/APAC regions)
  • Field-level encryption for sensitive fields
  • IP whitelisting + VPN tunnel support
  • Dedicated instance option (single-tenant deployment)
  • Custom DPA and BAA for HIPAA-adjacent use cases
